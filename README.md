# Neon Pinball｜电玩城倍率弹珠机

单人、纯虚拟弹珠的街机小游戏，基于 Canvas 和原生 JavaScript。

游戏规则：初始100颗弹珠；每局可通过 +1 / +5 / +10 逐步投珠，累计满5颗才随机揭晓2/4/6/8/10倍倍率及对应数量的红灯中奖槽，之后继续投入不重抽；在右侧向下拖动机械拉杆、松手按拉动距离发射；钢珠受重力及实体圆钉碰撞后落入底部槽位。落入红灯槽奖励投入×倍率，否则投入不返还。一颗钢珠只结算一次。**单次中奖所得不少于50颗弹珠获得一张奖励卡**，奖励卡只能兑换游戏内虚拟主题，不对应真实钱款或实物。

## 接入服务器

规划地址：`https://47.119.122.133/games/pinball/`

`main` 提交 → GitHub Actions 验证并将静态构建推送到 `site` → Game-Portal 独立部署器轮询并验证 → ECS 自动更新。**首次须在 ECS 的 Game-Portal 仓库运行**：

```bash
bash scripts/install-managed-static-ecs.sh --slug pinball --repo q894829927/Neon-Pinball
```

之后前端修改只需要提交 `main`。

## 玩法说明

详见游戏内部的规则面板；不使用真实货币，弹珠和卡片只为游戏内本地娱乐数据。存档位于当前浏览器 localStorage，不具备设备同步或服务端防作弊能力，真实奖品兑换不在此版本实现。

- **不再固定投入 10/20/50 颗**。在手机或电脑上按 +1、+5、+10 颗投入虚拟弹珠，投入会立即从可用余额扣除并累计到本局。

## v0.8.0 — 基于接触力学的二维钢珠仿真

- **连续导轨**：钢珠沿实际弧长参数化的竖直发射轨道及顶部三次曲线导轨运动，受到导轨切线方向的等效重力和阻力；末端沿轨道切向进入钉阵，不再在指定高度瞬移或被强制覆盖为一个固定的水平/竖直速度。
- **真实碰钉与自旋**：180Hz 固定物理步，钉阵内每步细分两次；采用球-圆 / 球-线段接触、法线反弹冲量、库仑切向摩擦和实心球转动惯量 `I=0.4mr²`。钢珠角速度随真实接触而变化（不是固定每帧自转），普通金属钉恢复系数 0.76、弹力碰撞器 0.92。
- **底部真实落槽**：全部 10 根分隔柱作为有限长度的碰撞线段从槽口延伸至槽底，球碰到隔板可反弹；钢珠下落撞到底部后会弹跳/滑移并消耗能量，达到稳定接触才按真实位置结算。删除原来的“刚过槽口立刻锁定位置，自动吸到槽位中心”逻辑。
- **有限的机械扰动**：发射速度 ±1.2%，导轨出口速度 ±1.2%，出口角度 ±0.86°；高于碰钉冲量阈值时额外切向误差不超过 3.5 像素/秒，约为正常碰撞速度的极小比例。随机扰动不根据奖励槽或倍率调整，不为中奖控制轨迹。
- **稳定性**：保留最大速度限制用于数值防护，并使用小步长减少穿钉。无真实 3D 深度、复杂变形和滚动空气动力学，因此属于高真实度的二维钢珠近似，而非完整 3D 刚体求解器。
- **回归检查**：新增连续导轨、不瞬移、撞击动量/自旋、隔板完整碰撞、多个力度与随机种子完成落槽等纯物理测试；Playwright 电脑端真实蓄力、发射、落槽和结算浏览器测试。

- 钉子与弹力器受到真实物理碰撞时产生局部闪光与扩散光环。钢珠拖尾根据速度和历史轨迹渐变，中奖槽在命中后短暂脉冲；不改动任何碰撞位置或开奖判定。
- 8×、10× 命中有不同的 JACKPOT 顶部文字、金色演出和简短三音提示；普通中奖保持简洁反馈。
- 尊重系统“减少动态效果”设置，禁用强动态效果，同时保留清晰的中奖结果。
- `public/arcade-feedback.mjs` 提供可测试的音效、轨迹和中奖特效参数；`tests/arcade-feedback.test.mjs` 检查强度、边界和倍率触发。


## v0.10.0 四幕机械兑奖与新奖励卡规则

- **奖励卡判定**：中奖返还弹珠每满 50 颗奖励 1 张，不跨局累积。例如本局返还 150 颗得到 3 张，返还 500 颗得到 10 张。
- **四幕出货**：中奖槽闪烁确认 → 机械出珠口逐颗吐出代表性银珠、余额逐步计数 → 机械出票口滑出奖励卡并飞到顶部卡片余额 → 完整结算面板。
- **性能与无障碍**：一局最多渲染 20 颗代表性钢珠和 3 张代表性卡片，界面始终显示实际奖励数量。玩家可点「跳过动画」或按 Escape 直接看结算；系统减少动态效果时立即显示结果。
- **安全性**：落槽时由 `settleFunded` 结算并持久化一次，动画只展示已经授予的弹珠和卡片，不会重复发奖。兑奖装置覆盖在 Canvas 上，不改变机台高度或手机布局。

## v0.10.1 机台内兑奖改造

- 移除 Canvas 顶部 MARBLE LUCK 视觉横幅，保留实体钉阵和发射轨道。

- 出货珠子在透明盆内统一坐标系下按重力、盆壁/盆底约束和球体接触移动，可在盆内堆积。展示数量最多20颗，数值仍按实际中奖数结算。
- 中奖后立即且仅一次保存奖励，动画支持点击跳过、按 Esc，减少动态效果时直接显示完整结果。保持手机完整缩放和页面不滚动。


## v0.10.2 圆形出珠口及按真实奖励数量绘制弹珠

## v0.10.5 实体弹珠兑奖物理

- 兑奖盆改用独立的二维圆形刚体碰撞求解器（`public/payout-physics.mjs`）：每颗钢珠具有实时位置/速度，受重力、盆底/盆壁反弹、钢珠两两碰撞与接触摩擦影响，采用120Hz固定积分步和空间哈希加速。
- 圆形出口按奖金数量逐渐释放真实物理钢珠；100、500等正常奖金逐颗进行物理模拟，大额奖金相应延长出珠时间（上限约5秒）；超过微型收集盆几何可容纳的极端奖励显示满盆，数字仍展示全部到账。
- 出珠完成、跳过动画、减少动态效果均使用**相同**求解器，结算后保留物理状态并自然停稳，不生成假落点、不重新整齐排列。派奖结算与持久化在动画开始前执行一次，与物理展示完全隔离。


## v0.10.6 固定尺寸钢珠和溢珠
- 出珠钢珠直径固定约 6.1 CSS 像素，与中奖颗数无关。500 颗与 10 颗的单颗大小一致。
- 物理盆壁改为真正的有限长边界：盆沿以下弹珠受到阻挡，堆到盆沿以上后可因碰撞和重力滚出盆边；部分钢珠也可能从兑奖装置边缘滚出视野。仍准确结算每一颗奖励。
- Canvas 扩展到整个兑奖接收区域，不再裁剪在玻璃盆内部。渲染模拟上限 850 颗用于控制极大金额时的 CPU 开销，但没有因数量增加而缩小钢珠。
